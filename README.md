# 🏋️‍♂️ Landing Page - Personal Trainer & Consultoria Online

Uma landing page de alta conversão desenvolvida para profissionais de educação física. O design utiliza uma paleta de cores escura (Dark Mode) com contrastes em tons de âmbar/dourado para transmitir energia, força e foco em resultados.

## 🎯 Objetivo do Projeto

Este projeto foi construído para o meu **Portfólio** com o objetivo de demonstrar habilidades práticas em estruturação semântica, estilização avançada sem frameworks (Vanilla CSS) e ambiente de desenvolvimento moderno utilizando Node.js. O layout foi pensado estrategicamente para guiar o usuário até a conversão via WhatsApp.

## ✨ Funcionalidades e Destaques Técnicos

*   **Design Responsivo:** Layout fluido que se adapta perfeitamente a dispositivos móveis, tablets e desktops utilizando Flexbox.
*   **Efeitos Visuais Avançados:** 
    *   Texto vazado com `-webkit-text-stroke`.
    *   Efeito *Glassmorphism* (fundo translúcido com desfoque) na barra de recursos.
    *   Transições suaves e efeitos de *hover* interativos nos cartões de serviços e planos.
*   **Integração Direta (Call to Action):** Botões programados para abrir o WhatsApp Web/App com mensagens personalizadas dependendo do plano escolhido.
*   **Navegação Smooth Scroll:** Links âncora no cabeçalho para navegação rápida entre as seções (Home, Sobre, Serviços, Planos, Depoimentos).

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estrutura semântica e acessível.
*   **CSS3:** Variáveis, Flexbox, Media Queries e animações.
*   **Node.js & NPM:** Gerenciamento do ecossistema local.
*   **Vite:** Ferramenta de *build* e servidor de desenvolvimento local extremamente rápido.
*   **Phosphor Icons:** Biblioteca de ícones vetoriais leves.
*   **Google Fonts:** Tipografia moderna (Montserrat / Poppins).

## 🚀 Como rodar o projeto localmente

Siga os passos abaixo para testar o projeto na sua própria máquina:

1. **Clone este repositório**
   
   git clone [https://github.com/SEU_USUARIO/landing-page-personal.git](https://github.com/SEU_USUARIO/landing-page-personal.git)
Acesse a pasta do projeto

2. **Instale as dependências**
    npm install

3. **Inicie o servidor de desenvolvimento (Vite)**
npm run dev

O terminal exibirá um link (ex: http://localhost:5173). Clique nele ou abra no seu navegador para ver o site em funcionamento.
